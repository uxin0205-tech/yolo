# BinaryQK／HOG／MASF 的收益歸因釐清

## 核對目的與結果

使用者詢問前面的 BinaryQK／HOG 是否有用，並推論加入 MASF 是否比較好。本次唯讀查核新方向各 summary 與既有梯度／HOG 診斷，不執行 GPU 或新增訓練。

BinaryQK：原正式 XNOR bool／integer reduction 的 Q/K score 梯度斷點已由前次真實路徑 probe 證實；training-only surrogate 保留精確前向並接通有限非零梯度，屬於已驗證的訓練功能修正。但原配對 E5 中，修正組 overall／person=0.5066236910／0.6268004012，原生對照=0.5070639150／0.6265093384，並非兩項均升。不可將後續解凍後段／head 微調的提升全部歸於 QK 修正。

A0 overall／person=0.5067385740／0.6268052740；後續 late E8=0.5081536354／0.6275205166，顯示整輪分段適應有部分恢復，但這不是 QK 單一變因的證明，也未回到官方 FP overall=0.5180192758。

HOG：共同比較 E4，HOG overall／person=0.5050581307／0.6261561705，原生=0.5058866581／0.6267297116；分別下降約 0.082853／0.057354 個百分點。HOG E4 patience 停止，此版不採用。HOG 是訓練輔助監督，不是最後推論加上的有效增準 head。小球 cell-center 覆蓋盲區是已見局部證據，不宣稱唯一降準原因。

MASF：新方向 bridge E8 overall／person=0.5082119552／0.6276641271，無 MASF Head control E8=0.5082670924／0.6276994546，仍略低。bridge 相較同樣已有 MASF 的原生 fork 小幅改善，只說明 bridge 比該訓練方式略好，不能反推加入 MASF 優於不加。舊 Pose 模型開關消融不納入這個新方向結論。

## 結論與限制

目前證據是：QK 訓練路徑已修正，但單項增準未證明；後續分段微調整體有恢復；此版 HOG 未帶來收益；新方向 MASF 尚未超過無 MASF 對照。沒有多 seed／獨立 test 證據支持微小差值的穩定性。不同階段的配對指標不能當成三個方法同條件排名。

困難：無。停止狀態不變，沒有修改模型、啟動 queue、刪除、commit 或 push。依使用者要求，保留所有既有結果並等待採用決定。
