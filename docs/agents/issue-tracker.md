# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue with `gh issue view <number> --comments`.
- List issues with `gh issue list`.
- Comment with `gh issue comment`.
- Apply or remove labels with `gh issue edit`.
- Close an issue with `gh issue close`.
- Infer the repository from `git remote -v`.

## Pull requests as a triage surface

PRs as a request surface: no.

## Skill operations

- When a skill says “publish to the issue tracker,” create a GitHub issue.
- When a skill says “fetch the relevant ticket,” read the corresponding GitHub issue.
- Wayfinding maps and child tasks are represented using GitHub issues and sub-issues.
