# B1R 與 P2/P3 Paper-Formula MFAM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正 B0→四尺度 P2 的 classification-tower 權重轉移，建立 staged/direct B1R 基準，並新增論文公式版 P2/P3 MFAM 五配方、獨立 pipeline、尺寸 AP 報告與安全 GPU 排程。

**Architecture:** 保留既有 Phase 1 程式與 `artifacts/static-phase1/` 不變，在 `masf_yolo/retest/` 建立獨立 context。B1R 沿用現有標準 P2 neck，但讓 Detect classification tower 逐尺度建構，確保 B0 的 P3–P5 head shapes 可完整轉移；P3 family 使用 B0 三尺度 graph 加單一 P3 slot。新 `PaperFormulaMFAM` 依論文式 (1)–(6) 實作，所有 Lite/Partial 配方共用相同雙 1×1 residual skeleton。

**Tech Stack:** Python 3.12、PyTorch 2.11、Ultralytics 8.4.90、PyYAML、faster-coco-eval 1.7.2、pytest、systemd user service、RTX 5090 FP16 profiling。

## Global Constraints

- 資料固定使用 `bbt5-detect-baseline/dataset/` 的 locked train/validation/test manifests。
- 初始化固定使用 `bbt5-detect-baseline/weights/yolo11m_bat_detect_init.pt`，SHA-256 為 `9adacdd1a86cde27b7568c0756ca06f7be83160445fc90a10449206c82b06f4d`。
- 所有結果標記 `data_exposed=true`；不得宣稱 leak-free generalization。
- 不使用 knowledge distillation、zero gate、learnable branch weights 或 test-driven selection。
- Phase 1 code paths、checkpoint、selection、report 與 artifacts 必須保持可重現且不被覆蓋。
- 新 artifacts 固定寫入 `artifacts/b1r-p2-p3-retest/`。
- GPU 工作只允許單一 queue，排在既有 GPU service 後，不啟動平行訓練。
- B1R staged 為 10 epochs backbone freeze 加 90 epochs full fine-tune；direct diagnostic 為同初始化全模型 100 epochs。
- P2/P3 MFAM variants 都先 3-epoch smoke，再以全模型不凍結、`lr0=0.001` 正式訓練 100 epochs。
- validation 用於 gate、選 parent、選 epoch；test 只在所有 selection 凍結後執行一次。
- 報告同時列 overall、Ball、Bat 的 AP/AP50/AP75/AP_S/AP_M/AP_L，以及 FP/FN、Params、GFLOPs、latency。
- `PaperFormula-Full` 只表示公式與 branch set 忠實；P2/P3-only placement、Lite、Partial、BBT5 設定明確標示為 adaptations。
